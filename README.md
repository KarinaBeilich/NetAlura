# 🎬 NetAlura - Clone Netflix

O **NetAlura** é uma réplica da interface da plataforma de streaming Netflix, focado na experiência do usuário (UX) e no desenvolvimento de componentes modernos de interface. O projeto foi estruturado durante a Imersão da Alura, aplicando conceitos fundamentais de desenvolvimento web para criar uma aplicação responsiva, fluida e com um design fiel ao original.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as principais tecnologias do desenvolvimento front-end moderno:

* **HTML5:** Estruturação semântica de toda a aplicação (banners, seções de vídeos, carrosséis).
* **CSS3:** Estilização avançada, utilizando propriedades como *Flexbox* e *Grid* para o alinhamento de layouts complexos, além de variáveis CSS para o gerenciamento da paleta de cores escura da marca.
* **JavaScript (ES6+):** Lógica para controle de interações na interface, manipulação do DOM e efeitos visuais dinâmicos.

---

## 🎨 Funcionalidades Praticadas

-   **Splash Screen Inspirada na Netflix:** Efeito de carregamento inicial em vídeo (overlay) antes de exibir a interface principal do catálogo.
-   **Banner Principal em Destaque:** Destaque para o título principal com botões estilizados de "Assistir" e "Mais Informações".
-   **Fileiras de Filmes (Categorias):** Listagem horizontal organizada por gêneros de conteúdo.
-   **Animações Smooth (Hover):** Efeitos visuais polidos ao passar o mouse sobre os cards dos filmes, aumentando levemente o tamanho do card para dar profundidade (efeito *zoom* sutil igual à plataforma original).
-   **Design Responsivo:** Adaptação da interface para garantir uma navegação confortável tanto em computadores quanto em dispositivos móveis.

## 🛠️ Como executar o projeto

1. Baixe ou clone este repositório na sua máquina.
2. Abra a pasta do projeto e dê dois cliques no arquivo `index.html`. 
3. O projeto abrirá direto no seu navegador de preferência!
